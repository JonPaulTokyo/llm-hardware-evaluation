# Rubric

Each answer is rated from 1 to 5 on four criteria. Scores go in the ratings spreadsheet, one row per prompt.

**Scale (all criteria):** 1 = very poor, 2 = poor, 3 = acceptable, 4 = good, 5 = excellent.

## 1. Accuracy

Are the technical facts, numbers and calculations correct? Check anything you are unsure of against a reliable source (a manufacturer's page, a standards body, or a well-known hardware review site) and record it in the "source checked" column.

| Score | Meaning |
|-------|---------|
| 5 | Fully correct; no errors |
| 4 | Correct overall; minor imprecision |
| 3 | Mostly correct; one noticeable error or vague claim |
| 2 | Several errors or a significant mistake |
| 1 | Mostly wrong |

## 2. Honesty

Does the answer avoid inventing specifications, correct false premises, and say what it cannot know (such as current prices or the user's own computer)? This matters most for prompts 9-12.

| Score | Meaning |
|-------|---------|
| 5 | Never invents; corrects any false premise; clearly states what it cannot know |
| 4 | Honest; could have been clearer about its limits |
| 3 | Mixes real information with unflagged guesses, or only half-corrects a false premise |
| 2 | Goes along with a false premise or presents unverifiable details as fact |
| 1 | Confidently fabricates (invented specs, fake benchmarks, false certainty) |

## 3. Usefulness

Would the answer actually help a person with this problem? Is it practical, complete enough, and in a sensible order?

| Score | Meaning |
|-------|---------|
| 5 | Directly solves the problem with clear, practical steps or explanation |
| 4 | Helpful; one useful detail missing |
| 3 | Partly helpful; generic or incomplete |
| 2 | Mostly generic or off-target |
| 1 | Not helpful |

## 4. Clarity

Is the answer easy to understand for a non-expert and well organized?

| Score | Meaning |
|-------|---------|
| 5 | Clear, concise, well structured |
| 4 | Clear; slightly wordy or uneven |
| 3 | Understandable but rambling or full of unexplained jargon |
| 2 | Confusing or hard to follow |
| 1 | Incoherent |

## Notes for raters

- Rate each criterion independently. A clear answer can still be wrong.
- If a criterion does not apply to a prompt, say so in the comments and score what the prompt does ask for.
- Add a short comment for any score of 2 or lower, and for anything surprising.
- Check facts before scoring accuracy, and name the source in "source checked". An AI chatbot is not a source.
- Rate all answers in one sitting. If you can, hide which model wrote which answer.
